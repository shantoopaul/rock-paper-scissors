# 🎮 Rock, Paper, Scissors

![Project Banner](./demo/Rock-Paper-Scissors.png)

## 📖 Overview
This is a modern, interactive, and fully responsive **Rock, Paper, Scissors** web game. Built with vanilla web technologies, it features smooth CSS animations, a dynamic scoring system, and a clean, user-friendly interface. Players can challenge the computer, track their scores, and easily access the game rules through a stylish modal popup.

## Main Technologies Used
- **HTML5**: Semantic markup for structured and accessible content.
- **CSS3**: Custom styling, flexbox layouts, and keyframe animations.
- **Sass (SCSS)**: Modular and maintainable stylesheet architecture (variables, mixins, and partials).
- **Vanilla JavaScript**: Core game logic, DOM manipulation, and event handling without any heavy frameworks.

---

## Key Features
- **Classic Gameplay**: Choose between Rock, Paper, or Scissors and compete against the computer's random selection.
- **Dynamic Scoreboard**: Real-time score tracking that updates based on wins and losses.
- **Smooth Animations**: Engaging CSS keyframe animations for circle selections, result reveals, and modal transitions.
- **Fully Responsive**: Optimized for all screen sizes (Desktop, Tablet, and Mobile) with tailored media queries.
- **Rules Modal**: A clean, accessible popup overlay to display game rules without leaving the page.
- **Play Again**: Instant reset functionality to clear the board and start a new round seamlessly.

## How to Run on a Local Machine

Follow these simple steps to get the project running on your local environment:

1. **Clone the Repository**:
   ```fish
   git clone https://github.com/shantoopaul/rock-paper-scissors.git
   cd rock-paper-scissors
   ```

2. **Open the Project**:
    Simply double-click the `index.html` file to open it in your default web browser.
    Recommended: Use an editor like VS Code and install the Live Server extension. Right-click on `index.html` and select "Open with Live Server" for a better development experience with auto-reloading.
